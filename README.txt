DATA PROTECTION ATLAS — GitHub Pages / BG + EN

Готов статичен сайт. Не са необходими инсталация на пакети или компилиране.

1. В GitHub Desktop: File > New repository.
2. Име: data-protection-atlas. Изберете Local path и Create repository.
3. Repository > Show in Explorer. Копирайте съдържанието на този архив
   директно в папката на новото хранилище, без допълнителна вътрешна папка.
4. index.html трябва да е непосредствено в основната папка, заедно с en/.
5. В Desktop: Summary = Add bilingual website; Commit to main.
6. Publish repository. Махнете Keep this code private. Publish Repository.
7. Repository > View on GitHub. В браузъра: Settings > Pages.
8. Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
9. Когато публикуването приключи, в Pages натиснете Visit site.

Типичен адрес: https://USERNAME.github.io/data-protection-atlas/
Английска версия: https://USERNAME.github.io/data-protection-atlas/en/
Заменете USERNAME с името на GitHub акаунта си.

За обновяване: сменете файловете в същата локална папка, после в Desktop
използвайте Commit to main и Push origin. Pages публикува обновлението.

Запазете структурата на файловете. .nojekyll е включен в архива.
Няма връзка с предишното хранилище на Sites и няма включени негови настройки.
Източниците на учебното съдържание са посочени в края на сайта.
